第 1 周

导入课表

可先在这里切换目标课表，导入不会影响其他课表。
第一次用：点上面那颗按钮，在学校列表里搜你学校的名字 （本校和带「适配」标记的社区适配库学校按字母排在一起 —— 每所由一段适配脚本自动把课表取回来）， 搜不到就用「手动输入」填一次教务地址，填完只存你本机。
进站后自己登录 → 翻到「学生个人课表」 → 点底栏那条的 「执行导入」，课表就进来了。
没有适配脚本的学校（自己手填地址那种）还有一条路：点课表页上教务系统 自己的「导出 / 下载课表」，下载会被自动接住、直接导入。
不用截图。也不上传你的数据 —— 地址、账号、课表都只落在本机。
支持五种文件，直接选原文件即可，不用转换：
· 教务系统「导出课表」下的 网页课表（.html，或伪装成 .xls 的网页表格）
· 教务处下发的 Excel 课表（.xls / .xlsx）
· 教务系统下载的 PDF 课表（.pdf）
· 按 A→G 列整理的 CSV 课表
CSV 列顺序（A→G）：课程名称、星期、开始节数、结束节数、老师、地点、周数

打开教务系统

载入适配库后，社区适配库里 200 多所学校会按字母列在下面： 每所由社区维护一段适配脚本，选中后会用它自动把课表取回来； 第一次要联网载入这份清单（约 75 KB，四条镜像任取一条通就行）， 载入一次就存在本机，之后离线也能用；
用过的学校会置顶。「我的学校」是你自己添加的，只存本机。
只填域名也行，例如 jwglxt.xxx.edu.cn；不确定登录页路径时点下面的「按正方规则补全」。 添加后同样存本机、可随时删除。
导入的学校只存在本机（不上传），会出现在上方列表里，可随时删除。

我的课表

每个课表各自独立保存课程与学期设置（开学日期、总周数、节数、作息时间）， 相互之间不会影响。点击课表名即可切换当前显示的课表。

设置

也可直接点周次栏最右边的月亮 / 太阳图标快速切换。
下面这些设置只对「当前课表」生效，不会影响其他课表。
用于计算「当前第几周 / 单双周」，可选择该周任意一天，程序会自动对齐到周一。
备份文件里是全部课表 + 设置（每节起止时间、学期第一周的周一、总周数都在）； 换手机时用它一次搬完。用 CSV / 教务导入只能带回课程，上面那几项会回到默认值。
