# 本地隐私词表（**示例文件**，可原样保留在仓库里）
# ──────────────────────────────────────────────────────────────────────
# 作用：冒烟测试与 APK 核验脚本会读词表，断言「这些词一个都不许出现在
#       出厂内容（web/）或验过的 APK 里」。
#
# 为什么真正的表不进仓库：
#   为了检查「源码里不许出现真实姓名」，把真实姓名原样抄进仓库，
#   这件事本身就是一次泄露 —— 判据变成了泄露源。所以分两份：
#     · 本文件 `privacy-words.example.txt` 只示范格式，**不要写真实信息**
#     · 真要禁的词写进 `privacy-words.local.txt`，它已被 .gitignore 排除,
#       只在你本机生效
#     · 没配那份表时，相关断言会打印「跳过」而不是失败 ——
#       别人 clone 你的仓库照样能全绿
#
# 格式：一行一个词；`#` 开头是注释；空行忽略。大小写敏感。
#       词可以是任意长度，会同时在 UTF-8 / UTF-16LE / UTF-16BE
#       三种编码下比对（所以对二进制文件也有效）。
#
#       ⚠️ 但「三编码比对」只对**没被压过**的东西有效：PDF 的内容流是 Flate 压的、
#          xlsx 是 zip —— 在这类文件上，**任何编码的字节比对都命不中**，
#          「查不出」会被读成「干净」。这类文件要先**摊开再扫**
#          （见 `smoke-test.js` 的 `privacyLayers()`）。
#          实测踩过：夹具里 3 个真实教师姓名 + 1 个真实楼栋就是这么过关的，而测试全绿。
